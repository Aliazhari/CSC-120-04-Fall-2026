# CSC-120-04-Fall-2026
Welcome to the CSC-120: Introduction to Computer Science course repository.

This repository contains lecture examples, demonstrations, practice programs, and other programming resources used throughout the course. It is designed to help students review concepts covered in class, practice programming outside the classroom, and experiment with code.

# About the Course

CSC-120 provides an introduction to computer science and fundamental programming concepts.

Throughout the course, students learn how to approach computational problems, design algorithms, write programs, and develop problem-solving skills using C++.

The examples in this repository complement the lectures and other course materials.
